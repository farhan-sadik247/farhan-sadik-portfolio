# Farhan Sadik - Personal Portfolio

A clean, modern, and responsive personal portfolio website showcasing my engineering projects, skills, and experience. Designed with a focus on performance and clean UI/UX.

## 🚀 Tech Stack

- **Framework:** [Next.js 16 (App Router)](https://nextjs.org/)
- **Library:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Form Handling:** [Web3Forms](https://web3forms.com/) & React Hook Form

## 🛠️ Features

- **Dark & Light Theme** support
- **Fully Responsive** design across all devices
- **Smooth Animations** and scroll transitions
- **Working Contact Form** (emails sent directly to inbox)

## 🏃‍♂️ Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the portfolio.
